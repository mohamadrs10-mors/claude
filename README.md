# حسابداری ساده (Simple Accounting)

برنامهٔ حسابداری ساده با Flutter برای **ویندوز** و **اندروید**؛ داده‌ها روی هر دستگاه در SQLite ذخیره می‌شود
و دو دستگاه از طریق شبکهٔ محلی (Wi‑Fi/LAN) با هم همگام می‌شوند. بدون نیاز به اینترنت یا سرور مرکزی.

## امکانات
- حساب‌ها (صندوق/بانک) با موجودی اولیه و مانده
- ثبت دریافت و پرداخت با دسته‌بندی، شخص و تاریخ شمسی
- اشخاص (بدهکار/بستانکار) و صورت‌حساب هر شخص
- فاکتور فروش و خرید با اقلام، تخفیف و ثبت پرداخت روی فاکتور
- گزارش ماهانه (درآمد، هزینه، خالص، به تفکیک دسته‌بندی) و جمع طلب/بدهی
- همگام‌سازی دوطرفه بین ویندوز و اندروید

## ساخت و اجرا
```
flutter pub get
flutter test
flutter run -d windows      # روی ویندوز
flutter build apk           # فایل نصبی اندروید
flutter build windows       # نسخهٔ ویندوز
```

## نحوهٔ همگام‌سازی
1. هر دو دستگاه به یک شبکه وصل باشند.
2. در بخش «همگام‌سازی» هر برنامه، آدرس خودش (مثل `192.168.1.20:8765`) نمایش داده می‌شود.
3. «کد اتصال» را در هر دو دستگاه یکسان کنید.
4. در یک دستگاه آدرس دستگاه دیگر را وارد و «همگام‌سازی الان» را بزنید (یا همگام‌سازی خودکار را روشن کنید).
   سرور فقط وقتی برنامه باز است در دسترس است. در ویندوز اگر فایروال پرسید، Allow بزنید.

### طراحی
- هر ردیف شناسهٔ UUID، زمان آخرین ویرایش، شناسهٔ دستگاه و شمارندهٔ تغییر محلی دارد؛ حذف‌ها «نرم» (soft delete) هستند.
- هر همگام‌سازی فقط ردیف‌های تغییرکرده از آخرین همگام‌سازی را در هر دو جهت می‌فرستد (`POST /sync`).
- تضاد: برای هر ردیف، آخرین ویرایش برنده است (با تساوی، شناسهٔ دستگاه تعیین‌کننده است).
- مانده‌ها ذخیره نمی‌شوند و همیشه از تراکنش‌ها محاسبه می‌شوند، پس بعد از همگام‌سازی همیشه درست‌اند.

### محدودیت‌ها
- ارتباط HTTP ساده (رمزنگاری‌نشده) با کد اتصال است؛ فقط در شبکهٔ مورد اعتماد استفاده کنید.
- ساعت دو دستگاه باید تقریباً درست باشد (برای تصمیم «آخرین ویرایش»).
- اگر دو دستگاه قبل از همگام‌سازی هر دو فاکتور جدید بزنند، ممکن است شمارهٔ فاکتور تکراری شود.
